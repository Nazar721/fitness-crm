# Міграція на Supabase: авторизація + зберігання даних

## Контекст

Зараз ВСІ дані в додатку — це хардкоджені `mock*` змінні всередині сторінок. Ні localStorage, ні sessionStorage не використовується. Створення тренування (`/workouts/new`) збирає дані в `useState`, але кнопка "Завершити" нічого не зберігає.

Supabase встановлений (`@supabase/supabase-js` v2.110.8) з повною типізацією 9 таблиць в `src/lib/supabase.ts`, але ніяких запитів до бази немає.

**Авторизація:** Google OAuth (один клік)
**Мета:** замінити mock дані на реальні дані з Supabase, забезпечити синхронізацію між пристроями. Не змінювати дизайн та UI.

## Крок 0: Створення Supabase проєкту

### Інструкція для користувача:
1. Перейти на https://supabase.com → Sign up → Create new project
2. Обрати регіон (Europe West - Франківськ ближче)
3. Записати `SUPABASE_URL` та `SUPABASE_ANON_KEY` з Settings → API
4. Створити `.env.local` з цими значеннями

### Налаштування Google OAuth:
1. Google Cloud Console → Create OAuth 2.0 Client ID (Web application)
2. Authorized redirect URIs: `https://<project-ref>.supabase.co/auth/v1/callback`
3. В Supabase Dashboard → Authentication → Providers → Google: вставити Client ID та Client Secret

### SQL міграція (виконати в Supabase SQL Editor):
Створити `supabase/migrations/001_init.sql` з 9 таблицями + RLS:

```sql
-- profiles
CREATE TABLE profiles (
  id UUID REFERENCES auth.users(id) PRIMARY KEY,
  email TEXT,
  name TEXT,
  avatar_url TEXT,
  age INTEGER,
  height INTEGER,
  current_weight NUMERIC,
  goal_weight NUMERIC,
  fitness_level TEXT,
  goal TEXT,
  available_equipment TEXT[] DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- workouts
CREATE TABLE workouts (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  date DATE NOT NULL,
  duration INTEGER,
  total_volume NUMERIC DEFAULT 0,
  notes TEXT,
  rating INTEGER,
  is_new_record BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- workout_exercises
CREATE TABLE workout_exercises (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  workout_id UUID REFERENCES workouts(id) ON DELETE CASCADE,
  exercise_id TEXT NOT NULL,
  order_index INTEGER DEFAULT 0,
  is_superset BOOLEAN DEFAULT FALSE,
  superset_group_id TEXT,
  notes TEXT
);

-- sets
CREATE TABLE sets (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  workout_exercise_id UUID REFERENCES workout_exercises(id) ON DELETE CASCADE,
  set_index INTEGER NOT NULL,
  type TEXT DEFAULT 'working',
  weight NUMERIC DEFAULT 0,
  reps INTEGER DEFAULT 0,
  rpe NUMERIC,
  tempo TEXT,
  duration INTEGER,
  distance NUMERIC,
  is_completed BOOLEAN DEFAULT FALSE,
  is_drop_set BOOLEAN DEFAULT FALSE,
  is_warmup BOOLEAN DEFAULT FALSE
);

-- personal_records
CREATE TABLE personal_records (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  exercise_id TEXT NOT NULL,
  type TEXT NOT NULL,
  value NUMERIC NOT NULL,
  date DATE NOT NULL,
  previous_value NUMERIC
);

-- measurements
CREATE TABLE measurements (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  date DATE NOT NULL,
  weight NUMERIC,
  chest NUMERIC,
  waist NUMERIC,
  hips NUMERIC,
  bicep NUMERIC,
  thigh NUMERIC
);

-- injuries
CREATE TABLE injuries (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  body_part TEXT NOT NULL,
  description TEXT,
  start_date DATE,
  end_date DATE,
  is_active BOOLEAN DEFAULT TRUE
);

-- badges
CREATE TABLE badges (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  badge_id TEXT NOT NULL,
  earned_at TIMESTAMPTZ DEFAULT NOW(),
  progress INTEGER DEFAULT 0
);

-- user_progress
CREATE TABLE user_progress (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE UNIQUE,
  xp INTEGER DEFAULT 0,
  level TEXT DEFAULT 'beginner',
  streak INTEGER DEFAULT 0,
  max_streak INTEGER DEFAULT 0,
  streak_freezes INTEGER DEFAULT 0,
  weekly_goal INTEGER DEFAULT 4,
  workouts_this_week INTEGER DEFAULT 0,
  last_workout_date DATE
);

-- RLS policies
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE workouts ENABLE ROW LEVEL SECURITY;
ALTER TABLE workout_exercises ENABLE ROW LEVEL SECURITY;
ALTER TABLE sets ENABLE ROW LEVEL SECURITY;
ALTER TABLE personal_records ENABLE ROW LEVEL SECURITY;
ALTER TABLE measurements ENABLE ROW LEVEL SECURITY;
ALTER TABLE injuries ENABLE ROW LEVEL SECURITY;
ALTER TABLE badges ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_progress ENABLE ROW LEVEL SECURITY;

-- Кожен користувач бачить тільки свої дані
CREATE POLICY "Users can view own profile" ON profiles FOR SELECT USING (auth.uid() = id);
CREATE POLICY "Users can update own profile" ON profiles FOR UPDATE USING (auth.uid() = id);
CREATE POLICY "Users can insert own profile" ON profiles FOR INSERT WITH CHECK (auth.uid() = id);

CREATE POLICY "Users can view own workouts" ON workouts FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "Users can insert own workouts" ON workouts FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "Users can delete own workouts" ON workouts FOR DELETE USING (auth.uid() = user_id);

CREATE POLICY "Users can view own exercises" ON workout_exercises FOR SELECT USING (
  workout_id IN (SELECT id FROM workouts WHERE user_id = auth.uid())
);
CREATE POLICY "Users can manage own exercises" ON workout_exercises FOR ALL USING (
  workout_id IN (SELECT id FROM workouts WHERE user_id = auth.uid())
);

CREATE POLICY "Users can view own sets" ON sets FOR SELECT USING (
  workout_exercise_id IN (
    SELECT we.id FROM workout_exercises we
    JOIN workouts w ON w.id = we.workout_id
    WHERE w.user_id = auth.uid()
  )
);
CREATE POLICY "Users can manage own sets" ON sets FOR ALL USING (
  workout_exercise_id IN (
    SELECT we.id FROM workout_exercises we
    JOIN workouts w ON w.id = we.workout_id
    WHERE w.user_id = auth.uid()
  )
);

CREATE POLICY "Users can manage own records" ON personal_records FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage own measurements" ON measurements FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage own injuries" ON injuries FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage own badges" ON badges FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage own progress" ON user_progress FOR ALL USING (auth.uid() = user_id);

-- Тригер: автостворення профілю при реєстрації
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO public.profiles (id, email, name, avatar_url)
  VALUES (NEW.id, NEW.email, NEW.raw_user_meta_data->>'full_name', NEW.raw_user_meta_data->>'avatar_url');
  INSERT INTO public.user_progress (user_id)
  VALUES (NEW.id);
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE OR REPLACE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

## Крок 3: API шар (CRUD)

Створити `src/lib/api/`:

### `profile.ts`
- `getProfile(userId)` → UserProfile
- `upsertProfile(userId, data)` → update профілю
- `getMeasurements(userId)` → Measurement[]
- `addMeasurement(userId, data)` → Measurement

### `workouts.ts`
- `createWorkout(userId, data, exercises, sets)` → зберігає тренування з вправами та підходами
- `getWorkouts(userId, limit?)` → Workout[]
- `deleteWorkout(workoutId)` → void

### `progress.ts`
- `getUserProgress(userId)` → UserProgress
- `updateProgressAfterWorkout(userId, workoutData)` → оновлює XP, streak, weekly count
- `getWeeklyVolume(userId, weeks?)` → для графіка об'єму
- `getExerciseProgress(userId, exerciseIds)` → для графіків брусів/турніка/відтискань
- `getMuscleBalance(userId)` → для радіального графіка
- `getActivityCalendar(userId, month?)` → для календаря

### `personal-records.ts`
- `getPersonalRecords(userId)` → PersonalRecord[]
- `checkAndUpdatePR(userId, exerciseId, weight, reps)` → порівнює з існуючим та оновлює

### `gamification.ts`
- `calculateLevel(xp)` → Level
- `checkBadges(userId, progress)` → нові badge'и
- `getDailyMissions(userId)` → DailyMission[]

### `export-import.ts`
- `exportAllData(userId)` → JSON з усіма даними
- `importAllData(userId, json)` → повне відновлення з JSON

**Файли:** всі в `src/lib/api/` (нові)

## Верифікація

1. `npm run dev` → додаток запускається
2. Redirect на `/auth/login` → кнопка "Google"
3. Google OAuth → redirect → головна з реальним ім'ям
4. Створити тренування → зберігається
5. Оновити сторінку → дані на місці
6. Увійти з іншого пристрою → ті самі дані
7. Експорт JSON → вийти → імпорт JSON → дані відновлені
8. Вийти → redirect на login
